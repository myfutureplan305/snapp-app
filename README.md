# Snappy — Mobile App

Snap a photo, tap **Explain** to learn what it is, or **Find** to see where to buy it.

## Run on your phone

1. Download **Expo Go** from your phone's app store
2. Go to snack.expo.dev
3. Create a new project and paste the code from App.js
4. Scan the QR code with Expo Go
5. Live testing on your phone — no build required

## For production deployment to App Store/Google Play

See Expo's official guide: https://docs.expo.dev/build/setup/
